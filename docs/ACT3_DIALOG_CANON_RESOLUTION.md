# Akt 3: Dialogresolution per beat

**Regel (högsta prioritet): Senaste uttryckligen godkända revidering vinner.** Källornas ordning i manifestet är inte kronologisk i manusarbetet. Ett restaurerat OCR-utdrag är **inte** en återställning av gamla namn eller beslut. GitHub-fragment och äldre dialogrubriker får inte automatiskt vinna över senare manusbeslut.

- **A3-PARK-021**: Använd den särskilt reviderade fullständiga dialogen i huvudmanifestets **11AU** efter commit `53d55b2`, inte PDF-draftens tidigare dialog.
- **A3-PARK-019, 020, 022**: Den återfunna originaldialogen i **11AU** är prioriterad framför äldre kondenserad synopsis; eventuella senare explicit godkända ändringar vinner.
- **A3-PARK-018**: Den upptäcker föräldrarnas namn/första dejt; 021 tillför Henriks **nya** minnen, ingen upprepning.
- **A3-HOME-004**: Identifierad PDF-lucka. Senare kompletteringsdialog finns, men får inte märkas som ordagrant återfunnen originalreplik.
- För andra beats med återställd PDF och senare rekonstruktion: använd PDF-ordalydelse **endast** där ingen senare explicit godkänd version motsäger den; markera obeslutade eller okontrollerade ändringar, gissa inte.

## Implementationsregel

1. Slå alltid först upp beat-ID här och läs dess senaste uttryckligen låsta canon-beslut i `ACT3_STORY_MANIFEST.md`.
2. Om flera versioner finns, kontrollera författad/godkänd senare revision före ordagranna arkivutdrag.
3. Använd arkiverad PDF för saknade ordagranna repliker, aldrig för att revert:a ändrade namn, åldrar, relationsfakta, datum, föremål eller senare reviderade scener.
4. Vid oklart företräde: markera beat som **källkonflikt** och behåll både texter; ändra inte tyst.
5. Kontrollera alla spelval och grenar för samma canon, inte bara huvuddialog.
